# 👋 MortimerDev

Side projects, small tools and the odd experiment from **[Andy Mortimer](https://mortimer.dev)**, a senior JavaScript engineer based in West Sussex, UK.

Things here are built to be genuinely useful: tools I want for myself, games for my kids, and apps for the people around me.

## 🚀 Live projects

| Project | What it is |
| --- | --- |
| [**mortimer.dev**](https://mortimer.dev) | My personal site, with handy developer tools that run in your browser |
| [**StackWarden**](https://stackwarden.com) | A developer hub for tracking tickets, ideas and projects across everything I build |
| [**Block Quest Maths**](https://blockquestmaths.com) | Block-building maths games that make practice feel like play |

More are in the works. Most repos stay private until they're ready.
